# Deepika Birthday Website — Fixed Creator Mode

The site opens in Visitor Mode, while the **Creator Mode 🔐** button is visible in the navigation.

Click **Creator Mode 🔐** and enter:

`deepika2026`

Creator Mode lets you edit the message, add/change music, set the birthday date, preview Visitor Mode, and save/lock.

The previous JavaScript initialization errors have been removed so the Creator button works directly.


## Music behavior
The birthday music is included locally in `music/website.mp3`. On phones, browsers require a user gesture before audio can start, so the website shows a simple first-touch screen. Tapping anywhere starts the music automatically and the prompt disappears. The music then loops continuously.
